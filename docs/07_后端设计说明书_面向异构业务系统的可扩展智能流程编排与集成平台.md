# 07_后端设计说明书

## 当前后端定位

后端当前处于“基础骨架已搭建、业务实现待补充”阶段。目录、分层、实体、Mapper 和 XML 已具备继续开发条件。

## 当前调用链路

```text
Controller
  -> Service 接口
  -> ServiceImpl 实现类
  -> Mapper 接口
  -> mapper_autoprocess XML
  -> MySQL
```

## 模块结构

| 模块 | 当前状态 |
|---|---|
| autoprocess-common | 已有统一响应、异常、ID 工具。 |
| autoprocess-entity | 已有核心实体和枚举，枚举字段已补注释。 |
| autoprocess-biz | 已有 Service 接口、ServiceImpl 占位、Mapper、XML、流程引擎占位。 |
| autoprocess-controller | 已有基础 Controller 和 DTO。 |
| autoprocess-server | 已有启动类、配置、Flyway SQL。 |

## Service 设计

| Service | 作用 | 当前状态 |
|---|---|---|
| ConnectorService | 连接器列表、动作测试、动作执行入口（动作按 connectorId + actionKey 定位）。 | 已建接口和实现占位。 |
| WorkflowDefinitionService | 流程定义查询、保存、发布。 | 已建接口和实现。 |
| EventGatewayService | 事件记录和触发流程入口。 | 已建接口和实现。 |
| WorkflowEngineService | 流程执行和审批恢复。 | 已建接口和实现占位。 |
| ApprovalService | 审批任务查询、通过、拒绝。 | 已建接口和实现。 |
| ExecutionQueryService | 实例和日志查询。 | 已建接口和实现。 |
| JsonDataService | JSON 字段序列化和解析。 | 已建接口和实现。 |

## Mapper 设计

Mapper 接口放在：

```text
backend/autoprocess-biz/src/main/java/com/autoprocess/mapper
```

SQL XML 放在：

```text
backend/autoprocess-biz/src/main/resources/mapper_autoprocess
```

当前 Mapper 只负责数据访问，不写业务逻辑。

## 开发注意事项

- Controller 不直接调用 Mapper。
- Controller 不直接依赖 ServiceImpl。
- Mapper XML 不写业务判断。
- 业务事务放在 ServiceImpl。
- 流程引擎不写死某个业务对象。
- 外部系统能力通过 Connector 和 ConnectorAction 扩展。
- 连接器动作通过 (connectorId, actionKey) 二元组定位，动作测试接口：`POST /connectors/{connectorId}/actions/{actionKey}/test`。
