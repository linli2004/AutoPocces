# 08_实现与测试计划

## 当前实现状态

当前工程已经完成基础骨架搭建，不属于功能完成阶段。后续开发需要在现有骨架上补充真实业务代码。

## 已完成

| 类型 | 内容 |
|---|---|
| 后端工程 | Maven 多模块结构。 |
| 后端分层 | Controller、Service 接口、ServiceImpl、Mapper、XML。 |
| 实体模型 | 连接器、动作、流程定义、实例、日志、审批、事件等核心实体。 |
| 枚举说明 | 流程状态、实例状态、审批状态、节点状态已补注释。 |
| 数据库脚本 | 平台核心表已建立。 |
| 前端工程 | Vue 3 基础结构、路由、菜单、页面入口。 |
| 构建验证 | 后端和前端均可构建通过。 |

## 推荐开发阶段

| 阶段 | 目标 | 交付 |
|---|---|---|
| 阶段 1 | 完善数据库与实体一致性 | SQL、Entity、Mapper XML 完全一致。 |
| 阶段 2 | 完成基础 CRUD | 用户、连接器、连接器动作、流程定义。 |
| 阶段 3 | 完成流程定义保存与发布 | 前端画布 JSON 能保存和读取。 |
| 阶段 4 | 完成事件触发与实例创建 | event_record、workflow_instance 正常写入。 |
| 阶段 5 | 完成流程引擎最小执行链路 | START、CONNECTOR_ACTION、IF、END。 |
| 阶段 6 | 完成审批暂停与恢复 | approval_task 与 workflow_instance 状态联动。 |
| 阶段 7 | 完成运行监控 | 实例、日志、错误信息可查询。 |
| 阶段 8 | 完成前端联调 | 页面功能与后端接口完全对应。 |
| 阶段 9 | 补充增强能力和测试 | Edge Agent、AI、测试用例、答辩材料。 |

## 测试策略

| 测试类型 | 重点 |
|---|---|
| 单元测试 | ServiceImpl、节点执行器、JSON 转换、状态流转。 |
| Mapper 测试 | XML SQL、字段映射、枚举字符串映射。 |
| 接口测试 | Controller 参数、响应格式、异常处理。 |
| 集成测试 | 事件触发、流程实例、节点日志、审批恢复。 |
| 前端联调 | 页面字段、接口路径、状态展示、错误提示。 |

## 当前验收标准

当前阶段的验收不是“业务闭环跑通”，而是：

- 目录结构合理。
- 文档与代码结构一致。
- 前后端能构建。
- 后端分层正确。
- Mapper 接口与 XML 位置正确。
- 实体和枚举字段含义清楚。
- 后续开发人员知道每个文件放在哪里、负责什么。
