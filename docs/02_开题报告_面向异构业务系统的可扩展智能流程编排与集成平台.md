# 02_开题报告

## 研究背景

企业内部常同时存在 ERP、CRM、OA、数据库、Excel、第三方 API 等多个系统。不同系统之间的数据流转、审批、通知和状态更新往往依赖人工操作，容易产生效率低、过程不可追踪、异常难定位等问题。

## 研究目标

设计并实现一个可扩展的智能流程编排与集成平台，使外部系统能力可以通过连接器注册到平台，再由流程设计器进行可视化编排，最终由流程引擎按照流程定义自动执行。

## 研究内容

| 内容 | 说明 |
|---|---|
| 连接器模型 | 抽象外部系统、接口动作、输入输出 Schema。 |
| 流程定义模型 | 保存节点、连线、节点配置和版本状态。 |
| 流程执行模型 | 创建实例、维护上下文、记录节点日志。 |
| 审批模型 | 流程执行中可暂停并等待人工审批。 |
| 事件模型 | 支持手动触发和 Webhook 事件接入。 |
| 前端设计 | 提供连接器、流程、实例、审批等页面入口。 |

## 可行性分析

- 技术可行：Spring Boot、MyBatis、Vue Flow、MySQL 均适合毕业设计落地。
- 数据可行：平台核心表已明确，业务数据不写死在平台中。
- 工程可行：当前已经完成前后端基础骨架，可继续进入真实业务编码。
