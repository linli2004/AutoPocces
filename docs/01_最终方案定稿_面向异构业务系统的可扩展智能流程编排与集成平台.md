# 01_最终方案定稿

## 课题名称

面向异构业务系统的可扩展智能流程编排与集成平台设计与实现

## 产品定位

本系统不是某个行业管理系统，而是一个通用流程编排与系统集成平台。平台通过连接器接入外部系统能力，通过流程画布编排节点，通过流程引擎执行节点并记录运行过程。

## 核心边界

- 平台对象：Connector、ConnectorAction、WorkflowDefinition、WorkflowInstance、NodeExecutionLog、ApprovalTask、EventRecord。
- 业务对象：订单、客户、工单、库存等只来自外部系统接口返回，不写死进平台主模型。
- 当前工程阶段只搭建基础骨架，不内置固定演示数据。

## 核心模块

| 模块 | 说明 |
|---|---|
| Workflow Designer | 前端流程设计器，保存流程定义 JSON。 |
| Workflow Engine | 后端流程执行引擎，后续补充真实节点调度逻辑。 |
| Connector Framework | 连接器和动作配置，统一描述外部系统能力。 |
| Event Gateway | 手动触发、Webhook 触发、事件记录。 |
| Approval Module | 人工审批任务和审批恢复。 |
| Edge Agent | 企业内网代理能力，当前作为增强模块预留。 |
| AI Service | 异常解释、字段建议等智能辅助能力，当前作为增强模块预留。 |

## 技术路线

- 后端：Spring Boot、Maven 多模块、MyBatis XML、MySQL。
- 前端：Vue 3、TypeScript、Element Plus、Vue Flow。
- 数据库：MySQL 8，核心 JSON 字段用于流程定义、上下文和节点输入输出。

## 当前结论

最终方向已经确定：先完成真实工程骨架，再逐步实现连接器管理、流程定义、流程执行、审批、日志和事件触发。后续开发不得把系统改成订单系统或单一业务管理系统。
