# 09_当前项目状态与后续开发路线

## 当前项目阶段

当前项目处于：

```text
工程基础骨架完成阶段
```

不是“功能完成阶段”，也不是“演示数据跑通阶段”。现在的价值是：目录结构、分层关系、核心实体、Mapper/XML 位置、前端页面入口都已经搭好，后续可以直接进入真实开发。

## 后续开发建议

1. 先把数据库、实体、Mapper XML 完全校准。
2. 实现用户、连接器、连接器动作基础 CRUD。
3. 实现流程定义保存、读取、发布校验。
4. 实现事件触发和流程实例创建。
5. 实现流程引擎最小可用调度。
6. 实现节点执行器。
7. 实现审批任务和审批恢复。
8. 实现运行实例、节点日志、事件记录查询。
9. 前端逐页联调。
10. 最后补充测试、答辩截图、增强能力。

## 开发纪律

- 不把业务对象写死进平台主模型。
- 不让 Controller 直接调用 Mapper。
- 不让 Controller 依赖 ServiceImpl。
- 不在 Mapper XML 写业务判断。
- 不新增无关模块破坏当前结构。
- 新能力优先在既有模块中扩展。

## 下一步最合适做什么

下一步建议先开发：

```text
连接器管理 + 连接器动作管理 + Mapper/XML 字段校准
```

原因是连接器是流程节点的数据来源。连接器能力稳定后，流程设计器、字段选择器、流程引擎才能继续往下做。
