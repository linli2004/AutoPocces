# 智能流程编排与集成平台文档索引

本目录用于指导当前工程后续开发。当前项目状态已经从“方案设计文档阶段”进入“工程骨架已搭建、等待真实业务开发阶段”。

## 当前开发基准

- 不内置模拟数据。
- 不以订单、ERP 或某个行业系统作为固定业务模型。
- 后端采用 `Controller -> Service接口 -> ServiceImpl -> Mapper接口 -> XML -> MySQL`。
- 前端保留基础页面入口，后续直接连接开发环境接口。
- 数据库以平台对象为主：连接器、连接器动作、流程定义、流程实例、节点日志、审批任务、事件记录、用户、代理、AI 日志。
