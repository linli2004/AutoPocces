# 06_前端设计说明书

## 当前前端定位

前端当前处于“基础页面入口已搭建”阶段，不内置固定业务演示页面。后续开发时直接连接开发环境后端接口。

## 当前页面

| 路由 | 页面 | 用途 |
|---|---|---|
| / | DashboardView | 运行总览入口。 |
| /connectors | ConnectorListView | 连接器和动作配置入口。 |
| /workflows | WorkflowDesignerView | 流程设计和流程定义入口。 |
| /instances | InstanceListView | 流程实例和节点日志入口。 |
| /approvals | ApprovalCenterView | 审批任务入口。 |

## 当前目录职责

| 目录 | 职责 |
|---|---|
| src/api | 后端接口封装。 |
| src/views | 页面入口。 |
| src/components | 通用组件和流程画布组件。 |
| src/types | 前端业务类型。 |
| src/router | 路由。 |
| src/settings | 菜单和系统设置。 |
| src/utils | 请求工具。 |

## 前端接口约定

- 请求路径不带 `/api` 前缀。
- 当前代理到 `http://localhost:8080`。
- 前端类型应与后端返回字段一致。
- 页面不直接拼接业务规则，业务规则由后端 Service 和流程定义承载。
- 连接器动作测试通过 connectorId + actionKey 定位，接口：`POST /connectors/{connectorId}/actions/{actionKey}/test`。

## 后续前端开发顺序

1. 完善连接器列表、新建、编辑、启停。
2. 完善连接器动作配置和动作测试表单。
3. 完善流程定义列表、保存、发布。
4. 完善流程画布节点库、节点配置面板、连线保存。
5. 完善运行实例列表、实例详情、节点日志抽屉。
6. 完善审批任务列表、审批详情、通过/拒绝操作。
7. 最后补充 Edge Agent、AI 辅助、权限菜单等增强页面。
