# 05_数据库设计说明书

## 数据库设计结论

数据库围绕平台核心对象建模，不内置固定业务数据表。业务对象来自外部系统接口或连接器动作输出，不作为平台主模型。

## 当前核心表

| 表名 | 中文名称 | 模块 |
|---|---|---|
| sys_user | 系统用户 | 用户与审批 |
| edge_agent | 企业内网执行代理 | Edge Agent 预留 |
| connector | 连接器 | Connector Framework |
| connector_action | 连接器动作 | Connector Framework |
| workflow_definition | 流程定义 | Workflow Designer |
| workflow_instance | 流程实例 | Workflow Engine |
| node_execution_log | 节点执行日志 | Workflow Engine |
| approval_task | 审批任务 | Approval Module |
| event_record | 事件记录 | Event Gateway |
| ai_assist_log | AI 辅助日志 | AI Service 预留 |

## 当前代码与数据库对应

| 数据表 | Entity | Mapper | XML |

| connector | Connector | ConnectorMapper | ConnectorMapper.xml |

| approval_task | ApprovalTask | ApprovalTaskMapper | ApprovalTaskMapper.xml |

说明：`sys_user` 的 Entity（SysUser）和角色/状态枚举已补充，Mapper、Service、Controller 待开发；`edge_agent`、`ai_assist_log` 当前已有 SQL 表，后续再补对应 Entity、Mapper、Service 和 Controller。

## 关键字段说明

| 字段 | 说明 |
|---|---|
| connector.type | 连接器类型，例如 HTTP、DATABASE、EMAIL、WEBHOOK。 |
| connector.auth_type | 认证类型，例如 NONE、BASIC、BEARER、API_KEY。 |
| connector_action.connector_id | 所属连接器；动作通过 (connector_id, action_key) 二元组定位，同一连接器内 action_key 唯一。 |
| connector_action.action_key | 动作标识；流程节点通过 connector_id + action_key 共同引用该动作。 |
| connector_action.input_schema | 动作输入参数结构，用于前端配置和后端校验。 |
| connector_action.output_schema | 动作输出结构，用于字段选择和上下文引用。 |
| workflow_definition.status | DRAFT、PUBLISHED、DISABLED。 |
| workflow_definition.definition_json | 流程节点、连线、节点配置。 |
| workflow_instance.status | RUNNING、WAITING_APPROVAL、COMPLETED、FAILED、REJECTED。 |
| workflow_instance.context_json | 流程运行上下文。 |
| node_execution_log.status | SUCCESS、WAITING、FAILED。 |
| approval_task.status | PENDING、APPROVED、REJECTED。 |
| event_record.status | 建议后续约定 RECEIVED、PROCESSING、SUCCESS、FAILED。 |
